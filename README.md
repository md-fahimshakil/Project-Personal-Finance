# মিতব্যয়ী — Get your APK (free)
1. Create a free account at github.com, then a new repo (e.g. "mitobyayi").
2. Upload ALL files in this folder (including the hidden .github folder) to the repo's main branch.
3. Open the repo's Actions tab > "Build APK" > wait ~5 min (run it manually via "Run workflow" if needed).
4. Open the finished run > Artifacts > download "mitobyayi-apk" > unzip > install app-debug.apk on your phone (allow "install unknown apps").
5. On first launch, allow notifications.
